### 👋 Welcome

Welcome to the GitHub home of **CGI Canada's Cybersecurity team**.
We help public and private sector organizations **anticipate, detect, respond to and recover** from cyber threats, so they can innovate and grow with confidence.

This organization hosts the tools, scripts, templates and technical content built by our team.
